# Магазин одежды собственного производства

Консольное приложение на Java. Магазин продаёт одежду, которую сам шьёт.
Можно добавлять изделия, продавать их со склада и смотреть, что скоро закончится.

Все данные хранятся в памяти, пока программа работает. После выхода всё пропадает.

## Как запустить

1. Открыть проект в IntelliJ IDEA.
2. Запустить класс `Main` 
3. Вводить команды в консоли.

## Команды

- `add <название> <категория> <размер> <цена> <количество>` — добавить изделие
- `list` — показать все изделия
- `get <id>` — показать изделие по номеру
- `sell <id> <количество>` — продать со склада
- `restock <id> <количество>` — добавить на склад новую партию
- `low` — показать изделия, которые заканчиваются или закончились
- `delete <id>` — удалить изделие
- `help` — список команд
- `exit` — выйти

Название пишется без пробелов, например `Худи_Классик`.
Категории: T_SHIRT, SHIRT, HOODIE, JEANS, DRESS, JACKET.

Пример:

    add Худи_Классик hoodie M 4990 5
    sell 1 2
    low

## Как устроен проект

- `entity` — изделие (`Garment`), категория и состояние склада (`StockLevel`)
- `ex` — свои исключения
- `repository` — хранение изделий в `Map`, где ключ — id
- `service` — логика: добавить, продать, пополнить склад
- `ui` — консоль: ввод команд и вывод на экран
- `ui.command` — сами команды, каждая в своём классе
- `util` — вспомогательные классы
